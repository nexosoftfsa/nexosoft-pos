LO ENCONTRASTE. EL EXENTO ERA LA BASE DE DATOS.
------------------------------------------------
Te debia esto hace tres vueltas, y lo destrabo el boton que te hice tocar:

    NOT NULL constraint failed: articulo.alicuota_iva

Traducido: la tabla de articulos de TU base se creo diciendo "la alicuota
de IVA no puede estar vacia". Y desde el 16 de septiembre, un producto
exento se guarda justamente asi, vacio — porque exento NO es lo mismo que
IVA 0% y no se pueden confundir.

Entonces la base rechazaba el arroz. Y aca esta lo que no se veia: el
catalogo se baja TODO JUNTO, en una sola operacion. Si un producto la hace
fallar, se cancela la operacion entera. No fallaba el exento: NO ENTRABA
NADA. Por eso durante tres vueltas viste "el catalogo no se actualiza" y no
"el exento no anda". Eran el mismo problema disfrazado.

Una instalacion nueva no lo tiene (la tabla ya se crea bien). La tuya viene
de antes, y esas tablas no se corrigen solas. Esta version las corrige al
arrancar, sin que tengas que hacer nada.


Y AL COMPARAR EL ORIGINAL CON EL DUPLICADO APARECIO ALGO PEOR
--------------------------------------------------------------
Vos pusiste: "EL DETALLE DEL IMPUESTO DIFIERE DEL ORIGINAL". Tenias razon, y
es mas grave de lo que parecia.

    Original (el papel)        Duplicado (desde Comprobantes)
    Subtotal neto  9.714,46    Subtotal neto  8.264,46
    IVA 0%             0,00    IVA 21%        1.735,54
    IVA 21%        1.735,54    Exento         1.450,00

Misma venta, mismo CAE. El duplicado estaba BIEN. El original —el papel que
se lleva el cliente— estaba MAL.

El motivo: el POS imprimia con su catalogo (el viejo, el que no podia
actualizarse) y el servidor le declaraba a ARCA con el suyo (el nuevo). Uno
decia IVA 0% y el otro decia exento, y nadie se podia enterar.

Cambie de quien manda: ahora el POS le dice al servidor con que alicuota
IMPRIMIO cada renglon, y el servidor declara ESA. El papel que tiene el
cliente en la mano es el comprobante; lo que se declara tiene que ser eso y
no una version recalculada despues.
