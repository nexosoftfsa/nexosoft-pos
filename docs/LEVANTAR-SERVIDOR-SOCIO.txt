===========================================================================
  NEXOSOFT - LEVANTAR EL SERVIDOR (no reinstalar)
  Para: Sebastian - "No se pudo conectar con el servidor"
  Tiempo: 3 minutos
===========================================================================

QUE PASA
--------
El error cambio: ya no dice que el usuario o la contrasena esten mal, dice que
no puede CONECTAR. O sea que el servidor no esta corriendo. No es un problema
de credenciales.

La culpa es mia y es de un cambio que hice ayer. Cuando le agregue al
instalador el paso que detiene PostgreSQL (hacia falta para poder reemplazar
sus archivos), quedo con solo 3 segundos de margen para volver a levantarlo
antes de migrar la base. Si no llegaba, el instalador se cortaba justo antes
de arrancar el servidor -- y como se cortaba despues de copiar todo, parecia
que habia terminado bien.

NO hace falta reinstalar. Hay un script que lo levanta.


PASO 1 - ABRIR POWERSHELL COMO ADMINISTRADOR
--------------------------------------------
Tecla Windows -> escribi "powershell" -> clic derecho -> Ejecutar como
administrador.

    [ ] Arriba de la ventana dice "Administrador".


PASO 2 - BAJAR EL SCRIPT
------------------------
Pega este renglon (es uno solo) y ENTER:

[Net.ServicePointManager]::SecurityProtocol = 'Tls12'; Invoke-WebRequest -Uri "https://raw.githubusercontent.com/nexosoftfsa/nexosoft-pos/main/scripts/instalacion/reparar-servidor.ps1" -OutFile "C:\NexoSoft-Servidor\scripts\reparar-servidor.ps1"

    [ ] No aparecio texto rojo.


PASO 3 - LEVANTARLO
-------------------
Pega este renglon, cambiando USUARIO y CLAVE por los que quieras usar para
entrar al POS. La clave tiene que tener 8 caracteres o mas.

& "C:\NexoSoft-Servidor\scripts\reparar-servidor.ps1" -AdminUsuario "USUARIO" -AdminPassword "CLAVE"

Va a tardar hasta un minuto. Al final tiene que decir:

    OK: Servidor respondiendo: ok, version 0.9.7
    OK: Usuario 'USUARIO' listo para entrar

y despues mostrarte la direccion del servidor.

    [ ] Dijo las dos lineas OK.

    Direccion que te mostro para ESTA PC: ______________________________


PASO 4 - ENTRAR AL POS
----------------------
4.1 Abri el POS.
4.2 Antes de entrar, tocá "Configuracion del servidor" (el enlace debajo del
    boton Ingresar) y fijate que la direccion sea EXACTAMENTE la que te
    mostro el paso 3. Normalmente:

        http://localhost:3000/api/v1

    [ ] Coincide (o la corregi y guarde).

4.3 Entra con el USUARIO y la CLAVE del paso 3.

    [ ] Entre.

Si entraste, terminaste. Avisame.


SI ALGO FALLA
-------------
El script dice en cada paso que fue lo que no pudo hacer. Copiame ese mensaje
y mandame ademas este archivo:

  C:\ProgramData\NexoSoft\logs\reparar-servidor.log

Con eso ya se exactamente donde se traba. No hagas nada mas: lo miramos.
