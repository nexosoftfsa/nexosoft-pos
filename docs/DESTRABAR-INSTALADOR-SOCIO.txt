PASO 1 - BAJAR POSTGRESQL DESDE OTRA VENTANA
--------------------------------------------
1.1 Sin cerrar el instalador, abri PowerShell como administrador.

1.2 Pega esto y apreta ENTER:

Stop-ScheduledTask -TaskName "NexoSoft cloud-api" -ErrorAction SilentlyContinue; Stop-ScheduledTask -TaskName "NexoSoft Actualizador" -ErrorAction SilentlyContinue; & "C:\NexoSoft-Servidor\postgres-portable\bin\pg_ctl.exe" stop -D "C:\ProgramData\NexoSoft\postgres-data" -m fast -w -t 30

1.3 Despues pega esto, que barre lo que haya quedado vivo:

Get-Process node,postgres,pg_ctl,cloudflared -ErrorAction SilentlyContinue | Where-Object { $_.Path -like "C:\NexoSoft-Servidor*" } | Stop-Process -Force

1.4 Y esto para confirmar que no quedo nada:

Get-Process node,postgres,pg_ctl,cloudflared -ErrorAction SilentlyContinue | Where-Object { $_.Path -like "C:\NexoSoft-Servidor*" } | Select-Object Id, ProcessName, Path

    [ ] No devolvio ninguna linea (vacio = perfecto).
