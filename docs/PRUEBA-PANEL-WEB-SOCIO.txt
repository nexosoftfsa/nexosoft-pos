PARTE 1 - PREPARAR (una sola vez)
===============================================================================

PASO 1.1 - Actualizar el POS
----------------------------
Abri NexoSoft y anda a:

    Configuracion  ->  Actualizaciones  ->  "Buscar actualizaciones"

Si ofrece una version nueva, instalala. El POS se reinicia solo.
Cuando termine, volve a Configuracion y fijate que diga:

    POS: 0.1.75      (o un numero mas alto)
    Servidor: 0.21.0 (o un numero mas alto)

    [ ] Anota lo que dice:  POS ________   Servidor ________

Si el servidor dice una version mas vieja que 0.21.0, usa el boton
"Actualizar servidor" de la misma pantalla (Windows pide permiso de
administrador y tarda unos minutos).


PASO 1.2 - Revisar las contrasenas ANTES de publicar
----------------------------------------------------
Esto es importante. Una vez que el panel este en internet, la contrasena es
lo unico que separa a un desconocido de los datos del comercio.

Anda a Configuracion y mira la tarjeta "Acceso remoto al panel".

  - Si NO aparece ningun aviso: segui al paso 1.3.
  - Si aparece un cartel que dice "Antes de publicar el panel, conviene
    reforzar estas contrasenas", con una lista de usuarios: es el sistema
    avisando que alguno tiene una contrasena floja.

    [ ] Aparecio el aviso?   [ ] No   [ ] Si
    Que usuarios nombraba: ____________________________________________

    Se cambian en Usuarios, con el boton "Contrasena" de cada fila. Con 12
    caracteres o mas, y que no tenga el nombre del comercio, alcanza. El
    cartel se actualiza solo apenas la cambias.

    [ ] El cartel desaparecio despues de cambiarla

La contrasena del usuario con el que vas a entrar al panel tiene que ser
una de las buenas.


PASO 1.3 - Activar el acceso remoto con el codigo
-------------------------------------------------
En la misma tarjeta "Acceso remoto al panel" aparece un campo que dice
"Codigo de activacion".

  1. Pega ahi el codigo que te mando Rodrigo.
  2. Debajo del campo tiene que aparecer:

         Va a quedar en https://socio.nexosoft.com.ar

     [ ] Dice socio.nexosoft.com.ar  (si dice otra cosa, PARA y avisale)

  3. Apreta "Activar".
  4. Windows te pide permiso de administrador: dale que si.
  5. Espera uno o dos minutos. No cierres nada.

QUE TIENE QUE PASAR: la tarjeta cambia y muestra la direccion
https://socio.nexosoft.com.ar con un codigo QR al lado, y debajo dice:

         "Se esta viendo bien desde afuera."

    [ ] Aparecio la direccion con el QR
    [ ] Dice "Se esta viendo bien desde afuera"

Si en cambio dice "Ahora mismo no responde desde afuera", espera tres minutos
y mira de nuevo (la direccion nueva tarda un rato en conocerse). Si sigue
igual, mira "SI ALGO NO FUNCIONA" al final.

OJO, UN AVISO: ese codigo, ademas del panel, ata esta PC a la suscripcion del
comercio "socio", igual que en la prueba de suscripcion. No tiene que
cambiarte nada: el comercio esta al dia. Si aparece alguna franja arriba del

SI ALGO NO FUNCIONA
===============================================================================

* Apretas "Activar" y da error.
  -> Copia el mensaje TAL CUAL y mandaselo a Rodrigo.
  -> Si dice que no encuentra cloudflared: el sistema lo descarga solo, pero
     necesita internet en la PC. Revisa que tenga y proba de nuevo.
  -> El detalle esta en:  C:\ProgramData\NexoSoft\logs\acceso-remoto.log

* Dice "Ahora mismo no responde desde afuera".
  -> Espera tres minutos y mira de nuevo: la direccion nueva tarda en
     conocerse.
  -> Revisa que la PC tenga internet.
  -> Mira si el tunel esta corriendo. PowerShell como administrador:
         Get-ScheduledTask -TaskName "NexoSoft Acceso Remoto"
     Tiene que decir "Running". Si dice "Ready" o "Disabled":
         Start-ScheduledTask -TaskName "NexoSoft Acceso Remoto"

* Desde el celular aparece una pagina de Cloudflare con un error (1033, 1016
  o parecido).
  -> Es que la direccion existe pero el tunel de la PC no esta corriendo.
     Es lo mismo de arriba: la tarea no esta andando.

* El panel carga pero no te deja entrar.
  -> Revisa que sea un usuario ADMIN o SUPERVISOR. Un CAJERO no puede.
  -> Si te equivocaste varias veces seguidas, la cuenta se bloquea un rato
     (es una proteccion). Espera unos minutos y proba de nuevo.

* El panel carga, entras, y las secciones salen vacias o con error.
  -> Anota que seccion y que dice, y mandaselo a Rodrigo. Si desde
     http://localhost:3000 (adentro de la PC) funciona y desde afuera no,
     es justo lo que vinimos a buscar.

* Si algo se rompe feo, los registros estan en:
        C:\ProgramData\NexoSoft\logs\
  Mandale esa carpeta a Rodrigo.
